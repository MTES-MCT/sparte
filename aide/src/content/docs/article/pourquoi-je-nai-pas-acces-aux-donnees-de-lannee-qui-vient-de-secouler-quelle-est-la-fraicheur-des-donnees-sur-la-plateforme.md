**Concernant les données de consommation d'espaces** : La fraîcheur est de l’ordre de 18 mois après la date de validité des données foncières MAJIC. Ce délai comprend :

* la mise à disposition par la DGFiP des fichiers MAJIC : 9 mois,
* les traitements génériques du CEREMA sur les fichiers MAJIC afin de créer les fichiers fonciers : 4 mois,
* les traitements spécifiques pour produire les données de consommation : 5 mois,

Pour plus d’informations sur les fichiers fonciers, produits par le Cerema, veuillez consulter la [FAQ sur le Portail de l’Artificialisatio](https://artificialisation.developpement-durable.gouv.fr/faq-publiee)n.

**Concernant les données sur l’artificialisation des sols** : d’ici septembre 2025, l’IGN produira deux millésimes de l’OCS GE pour chaque département (y compris les DROM : Guadeloupe, Martinique, Réunion, Mayotte, et Guyane en partie). Ces millésimes seront actualisés tous les trois ans. À ce jour :

* Cette production est soumise au [calendrier de l’OCS GE](https://artificialisation.developpement-durable.gouv.fr/carte-programmation-production-ocsge). Dès qu’un département est publié par l’IGN, nos équipes intègrent ces données le plus rapidement possible.
* Les millésimes disponibles varient selon les départements. Par exemple, pour le Gers (32), deux millésimes sont disponibles (2016 et 2019). Il est alors possible de calculer l’évolution de l’artificialisation des sols entre ces deux dates. Pour connaître les dates des millésimes par départements, vous pouvez [consulter les données ici](https://geoservices.ign.fr/ocsge-nouvelle-generation).
