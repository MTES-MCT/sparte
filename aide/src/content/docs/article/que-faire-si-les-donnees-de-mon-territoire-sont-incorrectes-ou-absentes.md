Il peut arriver que certaines erreurs apparaissent (données manquantes, anomalies de consommation, etc.).

Voici les bons réflexes :
👉 Attention : les données de référence nationales ne peuvent pas être modifiées rétroactivement par les producteurs (Cerema ou IGN), mais peuvent être **expliquées et contextualisées** dans vos rapports.

* Pour les **fichiers fonciers** : contactez <artificialisation@cerema.fr> ou <datafoncier@cerema.fr>.

* Pour les **données OCS GE** : utilisez la plateforme de signalement dédiée sur [osmose.numerique.gouv.fr](https://osmose.numerique.gouv.fr/jcms/p_6394777/fr/mtect-ocs-ge).
