Pour aller plus loin, vous pouvez télécharger les **données brutes** utilisées par Mon Diag Artif et les exploiter dans vos outils d’analyse géographique (ex. QGIS) :

* Données de consommation d’ENAF (Cerema) :
  👉 [Télécharger ici](https://cerema.app.box.com/v/pnb-action7-indicateurs-ff/folder/79850399955)
* Données d’artificialisation (OCS GE – IGN) :
  👉 [Télécharger ici](https://geoservices.ign.fr/ocsge)
  👉 [Consulter la carte de disponibilité par département](https://artificialisation.developpement-durable.gouv.fr/carte-programmation-production-ocsge)

Ces jeux de données permettent d’aller au-delà des visualisations proposées par Mon Diag Artif pour des analyses fines à l’échelle communale, intercommunale ou de SCoT.
