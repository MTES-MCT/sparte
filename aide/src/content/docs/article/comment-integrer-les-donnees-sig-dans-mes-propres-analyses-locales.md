Pour aller plus loin, vous pouvez télécharger les **données brutes** utilisées par Mon Diag Artif et les exploiter dans vos outils d’analyse géographique (ex. QGIS) :

* Données de consommation d’ENAF (Cerema) :
* A l'échelle communale (libre accès) :

👉 [Téléchargez ici](https://artificialisation.developpement-durable.gouv.fr/mesurer-la-consommation-despaces/telecharger-les-donnees)

* A l'échelle infra-communale (réservé aux ayants droits) :

👉 [Identifiez-vous et téléchargez les données sur Datafoncier](https://portaildf.cerema.fr/home)

* Données d’artificialisation (OCS GE – IGN) :

👉 [Télécharger ici](https://geoservices.ign.fr/ocsge)

👉 [Consulter la carte de disponibilité par département](https://artificialisation.developpement-durable.gouv.fr/mesurer-lartificialisation-avec-locsge/ocs-ge-acceder-aux-donnees)

Ces jeux de données permettent d’aller au-delà des visualisations proposées par Mon Diag Artif pour des analyses fines à l’échelle d'une collectivité ou à l'échelle parcellaire.
